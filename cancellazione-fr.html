Kilòmetro ne conserve pas vos données sur nos serveurs : elles se trouvent sur votre téléphone et, si vous avez choisi la connexion avec Google, dans votre Google Drive. C'est pourquoi vous pouvez les supprimer vous-même, immédiatement et en totalité, sans rien demander à personne. Si vous préférez, écrivez-nous et nous vous aidons.

1. Données sur le téléphone

  1. Ouvrez Paramètres → Applications → Kilòmetro → Stockage et touchez Effacer les données, ou désinstallez l'app.
  2. Sont supprimés : véhicules, dépenses, rappels, fournisseurs, préférences et le journal de diagnostic.

2. Données dans votre Google Drive

  1. Ouvrez Google Drive avec le même compte que celui utilisé dans l'app et supprimez le dossier Kilòmetro (il contient registro, foto, backup et export).
  2. Sur iPhone, si le registre est sur iCloud : Réglages → [votre nom] → iCloud → Gérer le stockage → Kilòmetro → Supprimer les données ; ou supprimez les fichiers du dossier Kilòmetro dans iCloud Drive.
  3. Sur Android, la sauvegarde automatique sur Drive s'arrête lorsque vous déconnectez le compte depuis l'onglet Plus de l'app ; les copies déjà enregistrées se suppriment avec le dossier.
  4. Videz la Corbeille de Drive pour le supprimer définitivement.
  5. Si vous avez partagé le dossier avec d'autres personnes, révoquez d'abord le partage depuis Drive.

3. Accès de l'app à votre compte Google

  1. Dans l'app : onglet Sync → Déconnecter le compte.
  2. Dans votre compte Google : Sécurité → Applications tierces ayant accès au compte → Kilòmetro → Supprimer l'accès.

Ce qui est supprimé et ce qui reste

  • Supprimés avec les étapes ci-dessus : toutes les données de l'app (registre des dépenses, sauvegardes, feuilles exportées) et l'association avec votre compte Google.
  • Rien ne reste chez nous, car nous ne recevons ni ne conservons de copies de vos données.
  • Si vous nous avez envoyé le journal de diagnostic par e-mail pour une assistance, nous le supprimons dans les 30 jours suivant la demande.
